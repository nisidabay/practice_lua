# Iterators — Custom Iteration

Build your own iterators: stateless, stateful, and the generic for loop.

## Structure

```
06_iterators/
├── concept/      # 6 teaching files covering core concepts
├── exercises/    # 5 interactive practice files with TODO sections
├── exercises.lua # Solved reference solutions
└── project/      # Fibonacci iterator
```

## How to Use This Group

1. Start with `concept/`: read each file in order
2. Practice with `exercises/`: each file has a `-- TODO` section for your implementation
3. Build the Fibonacci iterator

## Concepts Covered

- `pairs` vs `ipairs` behavior
- Stateless iterators (closure factories)
- Stateful iterators
- Fibonacci generator
- Generic `for` mechanics

## Project

**Fibonacci iterator** — a stateful iterator that yields Fibonacci numbers up to a configurable limit.
