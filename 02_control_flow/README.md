# Control Flow — Decisions and Loops

Master conditionals and iteration: if/else, while, for, and goto.

## Structure

```
02_control_flow/
├── concept/      # 7 teaching files covering core concepts
├── exercises/    # 5 interactive practice files with TODO sections
├── exercises.lua # Solved reference solutions
└── project/      # Number guessing game
```

## How to Use This Group

1. Start with `concept/`: read each file in order
2. Practice with `exercises/`: each file has a `-- TODO` section for your implementation
3. Build the number guessing game

## Concepts Covered

- `if` / `elseif` / `else` conditionals
- `while` loops with break
- Numeric `for` and generic `for`
- `repeat` / `until`
- `do` / `end` blocks for scoping
- `goto` and labels
- `break` in nested loops

## Project

**Number guessing game** — the computer picks a random number, the player guesses until correct, with hint feedback.
