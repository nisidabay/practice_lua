# Basics — Lua Fundamentals

Your first steps in Lua: variables, types, arithmetic, and printing.

## Structure

```
01_basics/
├── concept/      # 5 teaching files covering core concepts
├── exercises/    # 4 interactive practice files with TODO sections
├── exercises.lua # Solved reference solutions
└── project/      # Interactive calculator
```

## How to Use This Group

1. Start with `concept/`: read each file in order
2. Practice with `exercises/`: each file has a `-- TODO` section for your implementation
3. Build the calculator project

## Concepts Covered

- Variables and types: `string`, `number`, `boolean`, `nil`
- Arithmetic operators: `+`, `-`, `*`, `/`, `^`
- String concatenation with `..`
- `print()` and `type()` functions
- Global vs local scope

## Project

**Interactive calculator** — a menu-driven REPL that performs addition, subtraction, multiplication, division, and exponentiation.
