# Recommended Resources

## Official

- [Lua 5.4 Reference Manual](https://www.lua.org/manual/5.4/)

## Books

- *Programming in Lua* — Roberto Ierusalimschy (Lua's creator)
- *Lua Quick Start Guide* — Gabor Szauer
- *Beginning Lua Programming* — Kurt Jung
- *Lua Mini Reference* — Harry Yoon
- *Sysadmins: Scripting and Automation with Lua* — Mills R. (2024)

## Tools

- [LuaRocks](https://luarocks.org/) — package manager
- [lunajson](https://github.com/grafi-tt/lunajson) — pure-Lua JSON
- [inspect.lua](https://github.com/kikito/inspect.lua) — table pretty-printer
- [debugger.lua](https://github.com/slembcke/debugger.lua) — single-file Lua debugger (Scott Lembcke, MIT)
