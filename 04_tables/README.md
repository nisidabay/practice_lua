# Tables — Lua's One Data Structure

Arrays, hash maps, sorting, and nesting — all with a single construct.

## Structure

```
04_tables/
├── concept/      # 5 teaching files covering core concepts
├── exercises/    # 7 interactive practice files with TODO sections
├── exercises.lua # Solved reference solutions
└── project/      # Contact list manager
```

## How to Use This Group

1. Start with `concept/`: read each file in order
2. Practice with `exercises/`: each file has a `-- TODO` section for your implementation
3. Build the contact list manager

## Concepts Covered

- Array indexing (1-based!)
- Hash maps with string keys
- Nested tables (tables within tables)
- `table.insert` and `table.remove`
- `table.sort` with custom comparator
- Table as set (keys as membership test)

## Project

**Contact list manager** — a table-of-tables program that stores, searches, and lists contacts with name, email, and phone.
