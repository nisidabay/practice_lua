# Functions — First-Class Values

Functions are values in Lua: pass them, return them, capture state with closures.

## Structure

```
03_functions/
├── concept/      # 12 teaching files covering core concepts
├── exercises/    # 7 interactive practice files with TODO sections
├── exercises.lua # Solved reference solutions
└── project/      # Math utility library
```

## How to Use This Group

1. Start with `concept/`: read each file in order
2. Practice with `exercises/`: each file has a `-- TODO` section for your implementation
3. Build the math utility library

## Concepts Covered

- Function definition and multiple returns
- Varargs (`...`)
- Closures capturing local state
- Recursion and tail calls
- Factory functions
- Anonymous functions
- Functions as table values

## Project

**Math utility library** — a collection of reusable math functions demonstrating closures, recursion, and functional patterns.
